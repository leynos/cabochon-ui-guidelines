# Agent notes

This repository holds a Markdown book and generated SVG figures.

- Write in en-GB Oxford spelling, third person.
- Keep one chapter per Markdown file under `book/`.
- Figures live under `figures/` and are generated by
  `tools/make-figures.py`. Edit the generator, not the generated SVG.
- Run `make check` before committing. The SVG gate renders a proof sheet with
  `agent-browser`; read the screenshot rather than trusting XML validity alone.
- Prefer short, declarative chapters. Cross-reference other chapters by their
  relative Markdown path.
